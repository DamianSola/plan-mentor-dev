# Preguntas de entrevista para practicar

> Respondé en voz alta (1–2 min). Marcá las que te cuestan. Pedile al agente de Cursor: "Haceme de entrevistador con la sección React, una por vez".

## JavaScript / TypeScript
- [ ] ¿Qué es un closure? Dame un ejemplo real.
- [ ] Explicá el event loop: microtasks vs macrotasks.
- [ ] `==` vs `===`, `null` vs `undefined`.
- [ ] `var` / `let` / `const` y hoisting.
- [ ] ¿Cómo funciona `this`? ¿Qué cambia en arrow functions?
- [ ] Promesas vs async/await. ¿Cómo manejás errores?
- [ ] `interface` vs `type` en TS. ¿Qué son los genéricos?
- [ ] ¿Qué es `unknown` y por qué es mejor que `any`?
- [ ] Debounce vs throttle: ¿cuándo usás cada uno?

## React / Next.js
- [ ] ¿Qué dispara un re-render? ¿Cómo lo evitás?
- [ ] `useEffect`: dependencias, cleanup, errores comunes.
- [ ] `useMemo` vs `useCallback` vs `React.memo`.
- [ ] ¿Para qué sirve la `key` en listas?
- [ ] Estado local vs global (Context, Zustand, Redux): ¿cuándo cada uno?
- [ ] Componentes controlados vs no controlados.
- [ ] Next.js: SSR vs SSG vs ISR vs CSR. Server Components vs Client Components.
- [ ] ¿Cómo mejorarías el rendimiento de una página lenta?

## Node / Express / APIs
- [ ] ¿Cómo funciona Node siendo single-thread?
- [ ] ¿Qué es un middleware en Express? Ejemplo.
- [ ] ¿Cómo estructurás una API REST? Verbos y status codes.
- [ ] Autenticación: JWT vs sesiones. ¿Dónde guardás el token?
- [ ] ¿Cómo manejás errores y validación (ej. Zod)?
- [ ] CORS: qué es y cómo se configura.
- [ ] ¿Cómo protegerías una API de abuso? (rate limiting, validación, auth)

## SQL / Prisma / Bases de datos
- [ ] `INNER JOIN` vs `LEFT JOIN`. Escribí una query con `GROUP BY` y `HAVING`.
- [ ] ¿Qué es un índice? ¿Cuándo NO conviene?
- [ ] Normalización: ¿qué es y cuándo desnormalizar?
- [ ] Transacciones y ACID. Ejemplo con Prisma (`$transaction`).
- [ ] Problema N+1: qué es y cómo se evita en Prisma (`include`/`select`).
- [ ] SQL (PostgreSQL) vs NoSQL (MongoDB): ¿cuándo cada uno?
- [ ] ¿Cómo manejás migraciones en producción?

## Testing / Git / Calidad
- [ ] Unit vs integración vs e2e. ¿Qué testearías primero en Holos?
- [ ] ¿Qué es un mock y cuándo usarlo?
- [ ] `merge` vs `rebase`. ¿Cómo resolvés conflictos?
- [ ] ¿Qué incluiría un pipeline de CI básico?

## System design (básico)
- [ ] Diseñá un acortador de URLs (endpoints, modelo de datos, escalado).
- [ ] ¿Dónde agregarías caché en una app y qué invalidarías?
- [ ] ¿Cómo manejarías subida de archivos grandes?
